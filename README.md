# TSAI-AI

TSAI-OS 相关 AI 项目集合。包含多个独立子项目：

| 目录 | 说明 |
|------|------|
| `aai` | 语音 AI（Whisper 本地模型） |
| `aim` | Go 编写的 AI 中枢服务 |
| `ainote2` | AI 笔记应用 |
| `bai` | AI GUI 工具 |
| `chinai2` | 多后端 AI 客户端 |
| `clockai` | AI 时钟/定时任务 |
| `gh` | 手势识别（Gesture Recognition） |
| `hm` | AIM 中枢子系统（Python） |
| `hy` | AIM 客户端（Python） |
| `key` | 按键/快捷键增强 |
| `mgr` | AI PC 管理器 |
| `nai` | AI 文件聊天（Nautilus 扩展） |
| `phone` | KDE 手机端连接 |
| `scr` | 屏幕相关工具 |
| `se` | 模型管理器 |
| `wai` | Web AI 服务器 |
| `z` | AIM 知识库 |

各子项目均为独立工程，详见对应目录内的 README 或源码。
